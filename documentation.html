This project is a modern, production-grade Personalized Content Dashboard engineered to satisfy 100% of the requirements specified in the frontend engineering assessment brief. Built with Next.js 14 (App Router), React 18, TypeScript, Redux Toolkit, Tailwind CSS, and Framer Motion, the application delivers an engaging, intuitive, and cohesive lifestyle discovery platform.

Moving beyond generic dashboard templates, the platform—branded AuraFeed—features an authentic Indian Cultural & Regional Aesthetic centered around default user Sathyabhama (@sathyabhama.creative). Users can discover, interact with, filter, search, reorder, bookmark, and preview content spanning Editorial Magazine News, 70mm Cinema Masterpieces, Cozy Regional Music with Universal Apple AAC Playback, and an Instagram-style Social Media Experience with interactive stories.

4. Multi-Device Responsive Engineering

The application has been engineered and verified across mobile phones (320px–430px), tablets (768px–1024px), and desktops (1280px–1920px):

  • Thumb-Friendly Mobile Bottom Nav (MobileBottomNav.tsx): Renders on mobile devices (md:hidden) offering single-tap switching between Feed, Cinema, Music, Social, and News. Includes iOS safe-area inset adaptation (env(safe-area-inset-bottom)).
  • Adaptive Audio Player Docking: Docked dynamically at bottom-16 on mobile phones to float above the bottom navigation bar and at bottom-5 on desktop. Micro-screen viewports auto-collapse secondary buttons so play/pause remains unhindered.
  • Fluid Grid Breakpoints: Columns seamlessly transition from grid-cols-1 on narrow phones to sm:grid-cols-2 on tablets and lg:grid-cols-3 xl:grid-cols-4 on widescreen monitors.
  • Next.js Viewport Metadata: Explicit Viewport export with light/dark mobile theme colors for browser chrome integration.

5. State Management & Data Flow

Global state is managed via Redux Toolkit with slices operating in modular isolation:

Redux Slice Responsibility Persistence Mechanism
contentSlice Unified feed, section catalogs (news, cinema, music, social), pagination state, active audio track, active modal item. In-memory with async API Thunk triggers.
preferencesSlice Selected category realms, language preference, auto-play audio toggle, live updates flag. localStorage (aura_preferences_v2).
favoritesSlice User-bookmarked articles, films, tracks, and social posts. localStorage (aura_favorites_v1).
searchSlice Raw query, debounced query, categorized search results, recent search terms list. localStorage (recent searches array).
themeSlice Dark mode / Light mode toggle status. localStorage (aura_theme) + document class.
userSlice Profile credentials (name: Sathyabhama, handle: @sathyabhama.creative, bio, avatar). localStorage (aura_profile_v2).
feedOrderSlice Custom drag-and-drop order IDs for user-customized feed hierarchy. localStorage (aura_feed_order_v1).

6. Testing & Verification Suite

The test suite covers unit and integration test requirements specified in the evaluation rubric using Vitest and React Testing Library:

  • preferencesSlice.test.ts (6 tests): Validates category toggle, batch updates, reset defaults, and language selection.
  • favoritesSlice.test.ts (5 tests): Validates add/remove favorites, duplicate prevention, and category-specific filtering.
  • themeSlice.test.ts (2 tests): Validates dark/light mode toggles and HTML root class synchronization.
  • useDebounce.test.ts (3 tests): Verifies 400ms debounce timers, rapid typing input handling, and clean unmounts.
  • cards.test.tsx (4 tests): Renders News, Cinema, Music, and Social cards verifying props, badges, and action triggers.
  • languageFlow.test.tsx (5 tests): Verifies language selector dropdown, pills rendering, and feed re-fetch dispatches.
  • feedFlow.test.tsx (1 test): Verifies Redux dispatch of unified feed and DOM element generation.
  • searchFlow.test.tsx (1 test): Verifies modal opening, 400ms debounced queries, and multi-category grouped search results.
